# NaviParka Stage 6 — Premium Visual Redesign

This build keeps the MVP product content from Stage 5 but replaces the dark, repeated SaaS visual system with a brighter consumer mobility direction.

## Design changes
- Light-first warm neutral background system
- Floating white navigation with NaviParka blue CTA
- Larger, more expressive typography
- Dashed road/parking-line accent motif
- Dynamic Android screenshot compositions instead of static centered phones
- Blue hero visual field with floating product callouts
- High-contrast dark feature ribbon
- Bright three-step flow cards with a featured middle step
- Scanner product scene with callouts
- Clear parking-decision cards using green / amber / red state language
- Cobalt payment section with payment-provider and location-code callouts
- Overlapping profile/settings Android devices for vehicle + Blue Badge context
- Light timer/reminder/history utility cards
- Dark trust section reserved for emphasis rather than used across the whole site
- Lighter roadmap section that clearly labels the map as Version 2
- Reworked inner-page cards, forms, legal pages, footer and mobile navigation to match the new system

## Product truth remains unchanged
The current MVP is scanner-first and includes parking-rule interpretation, payment-service handoff where available, timer/reminders, scan history, vehicle context, Blue Badge mode and account/privacy controls. Parking map and directions remain roadmap features for Version 2.
